### B-3 / B-5 注册建议（T-004，依据 [ADR-0005](adr/0005-intercom.md)，核验日期 2026-10-23）

**为什么要认真选：** 小程序实时音视频组件（`live-pusher` / `live-player`）只对「开放类目表」内的企业类小程序开放，且必须类目审核通过后才能在后台自助开通；个人主体与测试号不能用。基线对讲方案（半双工 PTT，D-05）**不依赖**这些组件，所以选不到合适类目不会阻塞项目，只会失去全双工升级选项。

**B-3 注册小程序时：**

1. **主体类型：企业**（使用最终运营本系统的站段 / 项目公司的营业执照），完成微信认证（300 元/年）。不要用个人主体、个体户或测试号。
2. **类目：必须与实际业务相符。** 微信运营规范明确「类目不符」「滥用接口能力」会被限制能力直至下架，不能为了解锁接口而选无关类目。
   - **首选「工具 > 设备管理」**：它是微信「设备音视频通话」（方案 A）的接入前提，也是最贴近「机器人设备管理」的类目。要求营业执照经营范围含「硬件设备销售」等（请业主确认）。
   - **可选「IT科技 > 多方通信」或「IT科技 > 音视频设备」**：这是 `live-pusher` / `live-player` 开放类目表中唯一与对讲相符的行。**添加类目时后台会显示所需资质材料（可能涉及增值电信业务经营许可证）——请截图发给项目组；若业主没有对应资质，就不要硬选，直接放弃全双工升级即可。**
   - 一个小程序最多 5 个服务类目，上面两个可以同时申请。
   - ⚠️ 策划书 §4.4.2 里曾建议的「工具 > 办公/效率」**不在** `live-pusher` / `live-player` 的开放类目表内，请以本节为准。
3. 不要在 Phase 0 购买任何付费套餐（腾讯云 TRTC 包月套餐、微信设备 license）；需要试用时用免费体验版 / 体验 license。

**B-5 认证并通过类目审核后：**

1. 登录小程序后台 →「开发 > 开发管理 > 接口设置」，查看是否出现「实时音视频播放 / 实时音视频录制」；若有，点击开通；若没有或被拒绝，**截图并记录原文拒绝原因**（用于更新 ADR-0005 与风险 RK-01）。
2. 登录「功能 > 硬件设备」，截图其开通状态（仅记录，不要提交设备审核——除非业主决定评估方案 A）。
3. 提交截图给 A-2（不含 AppSecret、上传密钥等凭据；凭据一律走密钥托管）。

**完成后项目组做什么：** A-2 按 ADR-0005 §5 记录结果，更新 D-05 升级触发条件的满足情况，并通知 A-0。
