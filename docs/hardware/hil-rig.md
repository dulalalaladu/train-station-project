## 2. 机器人固定方式

目标：**四足离地**，机体不能走出台架，但保留腿部自由摆动（运动命令仍有效，用于验证厂商桥与回执），并能在 2 秒内释放/接住。

- 结构：4040 铝型材门架（F7）+ 腹部托架（宽托带或平板，避开电源口与散热口）+ 双吊带冗余；吊点位于机体重心上方，承重 ≥25 kg（Go2 约 15 kg；X30 另行核算）。
- 离地高度：脚底离地 ≥5 cm；托架水平，机体俯仰/横滚 <3°；脚下垫软垫，防止腿部过摆撞击台架立柱。
- 可复位：门架含升降装置（手动葫芦），保证无需二人抬举即可放下机体。
- 运动限制：台架测试中运动命令限速 ≤0.3 m/s、角速度 ≤0.5 rad/s；Go2 的翻转/舞蹈/倒立等表演动作在桥里**禁用**（CONTRACT §2 不暴露）。
- 线缆：以太网/电源线预留余量、走吊带外侧，防止腿部缠绕；功放、爆闪灯、CPE 装在机体上与实机一致，外挂电池固定牢靠。
- 散热：Orin NX 风道不得被托架遮挡；记录 `tegrastats` 温度，>85 ℃ 终止测试。
- 地面/围栏测试（落地行走）仅在 §6 的围栏内、监护人手持厂商遥控器时进行，速度 ≤0.3 m/s。

## 3. 音频回放与噪声注入

### 3.1 信号链

```
台架主机 (Ubuntu, F5)
  ├─ USB 音频接口 (F4) ─ 输出1 ─▶ 有源音箱A (“人嘴”：播放指令语料)  ──▶ 阵列 1 m
  │                        输出2 ─▶ 有源音箱B/C (噪声：粉红/站场噪声)  ──▶ 阵列 1.5 m ±45°
  │                        输入1 ◀─ 机体麦克风阵列线路输出 / 参考信号分路
  │                        输入2 ◀─ 声级计线路输出 (A/C 计权)
  │                        输入3 ◀─ 触发标记 (同步脉冲)
  └─ 网口 eth0/eth1 ─ netem 网桥 ─ CPE/Mesh ─ 云端或 mock 网关
机体：阵列(USB) ─ Jetson ─ 功放 ─ 号角喇叭 (距阵列 ≥0.5 m，朝外)；爆闪灯
```

- 采样 48 kHz/24 bit 多通道同步录制（人嘴、噪声、阵列原始通道、AEC 输出、参考、声级计、触发脉冲），**所有时延以同一块声卡时间线为准**。
- 语料：A-4 的指令语料（中文/方言/英文）与自由口语变体；采集/使用须遵守知情同意与脱敏（C-6），台架仓库不存真实人员录音。

### 3.2 校准（每次测试开始前，记录在日志）

1. 用 94 dB 校准器（F2）校准声级计。
2. 无噪声下，"人嘴"在阵列位置播放 1 kHz 参考音，调到 **65 dB(A)**（近似站场人员近讲 1 m）。
3. 噪声音箱在阵列位置分别校准到 **70/80/90 dB(A)**（粉红噪声与录制的鸣笛/机械/风声）。
4. SNR 0/5/10 dB ＝ 噪声电平相对 65 dB(A) 的语音电平设置；最终 SNR 以录音信号复算为准，并写入报告。

### 3.3 回声/AEC 测试要点

- **回灌路径验证（BOM B1 开放问题）**：主机通过阵列自身的 USB 播放通道输出喊话音频→线路输出→功放。录制"阵列原始麦克风通道"与"AEC 处理后输出"，计算 **ERLE ＝ 10·log10(P_raw / P_aec)**（无近端语音时）。建议验收线 ≥25 dB（⚠️ 暂定，待首批数据后由 A-0/A-4 确认）。若 XVF3800 的参考路径不成立，改用 B4 声卡 + `webrtc-audio-processing`，同一套测试复核。
- **削波/AOP 检查**：喇叭以 25%/50%/100% 功率播放，用声级计 C 计权峰值（dBC peak）在**阵列位置**测量；要求峰值 ≤ 麦克风 AOP −6 dB（AOP 取数据手册；未知时以录音波形无削波为准）。若削波，调整喇叭朝向/距离/挡板或限幅，直到通过（布局问题优先于算法）。
- **自激测试**：喇叭以 100 dB@1 m 循环播放预合成应答语 1 h，离线 KWS 与在线 KWS 同时运行，**自触发 0 次**（§10.2-4）。
- **双讲**：喇叭播放同时人嘴说命令词，统计 KWS 召回与 ASR 上行音频质量。

### 3.4 对讲声学回环（KPI-07）

在"小程序侧"（台架主机作为 mock 终端）发送脉冲音经网关/mock 中继到狗端喇叭，阵列拾音后回传，用多通道录音时间线计算往返时延 P50/P95（目标 P95 ≤1 s 单向口径由 A-5 在测试计划中固定）；soak 30 分钟统计断流次数（目标 0）。

## 4. 声级计测点

声级计（F1）三脚架高度与喇叭轴线同高；A 计权 Fast 用于语音可辨性，C 计权峰值用于削波；测量时旁人离开轴线前方。

| 测点 | 位置 | 目的 | 记录 |
|---|---|---|---|
| M1 | 喇叭轴线 **1 m** | 验证 ≥100 dB@1 m 能力（BOM B3）；音量档位–声压对应表 | dB(A) Fast、dBC peak |
| M2 | **阵列位置**（贴近阵列外壳） | 削波/AOP、耦合声压、AEC 输入电平 | dBC peak、dB(A) |
| M3 | 轴线 3 m | 衰减曲线、可辨性 | dB(A) |
| M4 | 轴线 5 m 与 ±45° 偏轴 5 m | 覆盖范围、指向性 | dB(A) |
| M5 | 操作员耳位（1.5 m，偏离轴线 90°） | 听力安全：>85 dB(A) 必须戴耳罩 | dB(A) |
| M6 | 房间四角 | 背景噪声（测试前后各测 1 分钟） | Leq |

输出：音量档位–M1/M3 声压表（交给 T-109 做音量自适应与限幅）。

## 5. 断网与弱网模拟

### 5.1 拓扑

```
机体 Jetson ─ (eth) ─ CPE/Mesh ─ 台架主机 eth1 ═[netem 网桥/路由]═ eth0 ─ 上联 (云端/mock 网关)
                              └─ 智能断电开关 (F6) 控制 CPE 电源
```

台架主机开启转发（`net.ipv4.ip_forward=1`），在**两个方向**的出口网卡上各挂 netem（一块网卡只作用于其出方向）。

### 5.2 命令模板（需 root；仅限台架网络，执行前确认网卡名，不得在生产网络上运行）

```bash
# 丢包 + 时延 + 抖动
sudo tc qdisc add dev eth1 root netem loss 20% delay 100ms 20ms
sudo tc qdisc add dev eth0 root netem loss 20% delay 100ms 20ms
# 改参数 / 恢复
sudo tc qdisc change dev eth1 root netem loss 40% delay 500ms 50ms
sudo tc qdisc del dev eth1 root; sudo tc qdisc del dev eth0 root
# 硬断网 10 s / 60 s / 10 min（二选一）
sudo ip link set eth1 down; sleep 10; sudo ip link set eth1 up
# 断电 CPE：由智能开关 (F6) 执行 off → 等待 → on，记录时间戳
```

矩阵（§10.2-1）：丢包 0/5/20/40% × RTT 50/200/500 ms；断网 10 s/60 s/10 min。每格记录：指令可达率、重复执行次数（必须 0）、过期指令拒绝、离线 KWS 接管时间（≥5 s 检测，§4.3.4）、恢复后对账。

## 6. 安全围栏与急停

**人员与场地**

- 台架测试区用围栏/隔离带形成 **≥2 m 的隔离区**，入口挂"机器人测试中"标志；运动命令发出期间区内**无人**，调试需要进入时先停机（桥 `stop()` + 厂商遥控器确认站立/阻尼）。
- 至少两人在场：**操作员**（键盘/脚本）与**监护人**（手持厂商遥控器和台架急停，不看屏幕）。
- 喇叭/爆闪测试：人员戴耳罩（F10）；喇叭对准空旷方向；爆闪灯避免对眼睛直射；癫痫风险提示。
- 电池：使用 LiFePO4 并带保险；充电与存放不在测试区；机体与外挂电池分别配置灭火毯/灭火器。
- 落地行走测试：围栏不小于 3 m × 3 m，地面平整，速度 ≤0.3 m/s，开启厂商避障，监护人持遥控器；记录机型/固件/SDK commit。

**三层急停（互相独立）**

| 层 | 手段 | 说明 |
|---|---|---|
| 1 软件 | `dog/<id>/cmd/urgent` → `bridge.stop()`；本地 KWS 急停词；脚本一键 `stop` | ≤100 ms 目标；本层由 H-1 测量 |
| 2 厂商 | 厂商手持遥控器的阻尼/急停组合键（以官方手册为准 ⚠️，**未在本 spike 核实**） | 监护人专用；开测前演练 |
| 3 台架 | 蘑菇头急停（F8）切断**外设**（功放、爆闪、CPE）电源；机体电池可快速断开（XT60 插头可达）；门架葫芦快速放下 | 不替代厂商急停：切外设电源不会让机器人停下 |

**开测检查单**（每次运动测试前打勾并写入日志）：围栏就位 □　监护人持遥控器 □　台架急停通电可复位 □　软件 stop 演练通过 □　吊带检查 □　电池/外挂固定 □　限速已设 ≤0.3 m/s □　无人在隔离区 □。
