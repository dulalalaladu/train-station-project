# xfyun-spike (T-003)

Minimal, SDK-free clients for the three Xunfei interfaces used by the voice
pipeline, plus a local replay server. Design notes and ✅/⚠️ status of every
protocol detail: [`docs/adr/0003-xfyun-interfaces.md`](../../docs/adr/0003-xfyun-interfaces.md).

| Command | Interface | Endpoint |
|---|---|---|
| `slm` | Dictation large model (中英) | `wss://iat.xf-yun.com/v1` |
| `multilingual` | Multilingual large model | `wss://iat.cn-huabei-1.xf-yun.com/v1` |
| `rtasr` | Real-time transcription large model | `wss://office-api-ast-dx.iflyaisol.com/ast/communicate/v1` |

## Setup

```sh
cd tools/xfyun-spike
npm install            # Node >= 24; TypeScript runs natively (type stripping)
npm run typecheck && npm run lint && npm test
npm run coverage       # thresholds: 80% lines/functions/statements
```

## Offline run (no keys, no network)

```sh
npm run mock                                   # terminal 1: listens on 127.0.0.1:8765
node src/main.ts slm --audio fixtures/en-return-to-base.pcm --mock ws://127.0.0.1:8765 --runs 3
node src/main.ts multilingual --audio fixtures/en-stop.pcm --mock ws://127.0.0.1:8765 --language en_us
node src/main.ts rtasr --audio fixtures/en-follow-me.pcm --mock ws://127.0.0.1:8765
```

`--mock` only accepts loopback URLs and uses fake credentials. Mock latencies
say nothing about the real service.

## Real run (needs keys from the secret store)

Credentials are read **only** from the environment; missing variables abort
with the names of the missing variables (never a placeholder request):

| Interface | Variables |
|---|---|
| `slm`, `multilingual` | `XFYUN_APP_ID`, `XFYUN_API_KEY`, `XFYUN_API_SECRET` |
| `rtasr` | `XFYUN_APP_ID`, `XFYUN_RTASR_ACCESS_KEY_ID`, `XFYUN_RTASR_ACCESS_KEY_SECRET` |

```sh
node src/main.ts slm --audio fixtures/en-stop.pcm --runs 20 --ltc 3 --out report-slm-ltc3.json
```

The JSON report (texts, error list, first-result / final latency P50/P95) never
contains keys or signed URLs. Do not commit reports that contain real
recordings' transcripts.

## Fixtures

`fixtures/*.pcm` are **synthetic** (Windows SAPI en-US, 16 kHz/16 bit/mono raw)
generated by `scripts/make-fixtures.ps1`. No real-person recordings may be
committed. Chinese fixtures need a zh-CN TTS voice, which stock Windows lacks.

## Layout

```
src/auth/        IAT (HMAC-SHA256) and RTASR (HMAC-SHA1) signed URLs
src/protocol/    frame builders / zod response parsers
src/merger/      wpgs apd/rpl + rg dynamic-correction merger (immutable)
src/audio/       1280 B / 40 ms chunking + drift-free pacing, WAV header strip
src/clients/     slm + multilingual (shared IAT session), rtasr
mock/            local replay server that verifies signatures
tests/           unit + end-to-end tests against the mock
```

Latency definitions: **first-result** = first non-empty text, from the first
audio frame sent; **final** = IAT `header.status=2` (RTASR: stream close after
`{"end":true}`), from the last frame / end message sent.
